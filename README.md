Semiconductor Data Analysis 🔬

A beginner Python project for cleaning and analysing semiconductor material data.

🛠️ Technologies
1. Python
2. Pandas
3. NumPy
4. Matplotlib

✨ Features

-- Read semiconductor data from a CSV file.
-- Detect missing values.
-- Fill missing numerical values using column means.
-- Check whether missing values remain.
-- Visualise semiconductor properties (planned).

🚀 How to Run

Install the required libraries:
```sh
pip install pandas numpy matplotlib
```

Run the program:
```sh
python main.py
```

Make sure semi.csv is in the same folder as main.py.
